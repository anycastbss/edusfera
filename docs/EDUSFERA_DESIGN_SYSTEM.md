# Дизайн-система Edusfera Aurora (Design System Specification)

Дата утверждения: Октябрь 2026 г.  
Версия: **v3.0 Aurora Mobile & Desktop**  
Статус: **Действующий стандарт платформы**

---

## 1. Философия и визуальный манифест

Дизайн-система **Edusfera Aurora** построена на принципах бескомпромиссной эргономики, кинетической энергии и визуального воздуха:
- **Dark Mode First**: глубокий тёмный матовый фон снижает нагрузку на зрение при многочасовых занятиях и создаёт эффект премиального инструмента.
- **Один главный акцент (One Accent Rule)**: правило пропорции **60 / 30 / 10**:
  - **60%** — глубокий тёмный фон (`#0B0B0E` / `#121214`).
  - **30%** — стекло, нейтрали и защитные подложки (монохром, slate-тексты, полупрозрачные грани).
  - **10%** — яркий фирменный акцент: кинетический фиолетовый (`#7D39EB`) и электрический лайм (`#C6FF33`).
- **Контраст масштаба (Scale Contrast)**: сочетание мощных контрастных заголовков (font-black, tracking-tight) и ультракомпактных системных бейджей (10-11px, font-mono, tracking-wider).
- **Визуальный отклик на каждое действие**: любое касание, клик или переключение сопровождается упругой физической анимацией (`whileTap={{ scale: 0.97 }}`), сменой свечения и мгновенной реакцией интерфейса.

| Токен | HEX | Применение |
| :--- | :--- | :--- |

### Текст и контрастность (WCAG 4.5:1+)
- **Primary Text**: `#FFFFFF` (100% непрозрачный белый) — заголовки, имена, ключевые цифры.
- **Secondary Text**: `#94A3B8` (Slate-400) — пояснения, подписи к полям, даты.
- **Muted Text**: `#64748B` (Slate-500) — второстепенные подсказки, таймстампы.

## 3. Стандарт Глассморфизма (Glassmorphism & Frosted Glass)

Парящие панели, док-панели и карточки виртуального класса обязаны соответствовать физической формуле стекла:

```css
/* Стандарт стеклянной панели Edusfera Aurora */
.aurora-glass {
  background: rgba(18, 18, 20, 0.78);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.12);
  box-shadow: 
    0 16px 36px -4px rgba(0, 0, 0, 0.5),
    inset 0 1px 1px 0 rgba(255, 255, 255, 0.25);
  border-radius: 24px;
}
```

### Защитные правила стекла:
1. **Запрет `opacity` на родителя**: никогда не задавать свойство `opacity` блоку, содержащему текст (текст должен быть на 100% чётким).
2. **Ограничение размытия**: оптимальный диапазон `12px – 20px`. Размытие свыше 30px запрещено на динамических списках для сохранения 60 FPS на смартфонах.
3. **Верхний блик (Glass Inset Highlight)**: обязательный `inset 0 1px 1px rgba(255, 255, 255, 0.25)` создаёт эффект объёмной полированной стеклянной грани.

## 4. Сетка, отступы и радиусы (8pt Grid System)

### Отступы (Spacing Scale)
Все отступы строго кратны **8px** (допустимы половинные шаги 4px для микро-бейджей):
- `4px` — `gap-1` / `p-1` (внутренние чипы)
- `8px` — `gap-2` / `p-2` (компактные кнопки, расстояния между иконками)
- `12px` — `gap-3` / `p-3` (стандартные плашки, бейджи)
- `16px` — `gap-4` / `p-4` (внутренний отступ карточки)
- `24px` — `gap-6` / `p-6` (отступы секций, BottomSheet padding)
- `32px` — `gap-8` / `p-8` (зазоры между блоками экрана)
- `48px` — `min-h-[48px]` (минимальная тач-мишень для мобильных пальцев)

### Скругления (Border Radius Hierarchy)
- **Xs (8px)**: теги, подсказки, всплывающие подсказки.
- **Md (12px)**: поля ввода, кнопки второго уровня, переключатели слайдов.
- **Lg (16px)**: карточки уроков, видео-плитки, чипы выбора времени.
- **Xl (24px)**: парящие островки (Floating Islands), видео-остров, плавающий док.
- **2Xl (32px)**: шторки (BottomSheets), модальные окна, заглавные баннеры.
- **Full (9999px)**: круглые кнопки управления медиа (Mic, Cam), статусные пилюли.

## 5. Компонентные стандарты

### 1. Плавающий док управления (Floating Island Dock)
- Располагается по центру в нижней части экрана с парением над холстом (`bottom: 20px`).
- На мобильных устройствах учитывает `env(safe-area-inset-bottom)`.
- Содержит круглые кнопки размером не менее **48×48px** с интуитивными иконками.
- **Мобильный лимит**: Строго максимум **6 кнопок** на мобильном экране (`Микро`, `Камера`, `Звонок`, `Чат`, `Ещё`, `Выход`), ширина капсулы $\le 312$px. Никаких боковых обрезок текста и горизонтального переполнения на экранах 360–393px.
- Активные состояния:
  - Микрофон включен: тёмное стекло с белой иконкой или акцентный фиолетовый.
  - Микрофон выключен: красный/розовый фон (`rgba(239, 68, 68, 0.2)`) с красной иконкой перечёркнутого микрофона.
  - Камера включена: стекло или фиолетовое свечение.
  - Главная кнопка перехода: неоновый лайм (`#C6FF33`) с чёрной иконкой.

### 2. Видео-остров (Floating Video Island)
- **Режим Picture-in-Picture (PiP)**:
  - Парящий блок со скруглёнными углами 16–20px, тонкой стеклянной рамкой и тенью парения.
  - На смартфонах PiP компактно пристыкован в правом нижнем углу над доком (`bottom: calc(safe-area + 68px); right: 12px; width: 120px;`), чтобы верхняя половина экрана и панель инструментов доски оставались на 100% свободными для письма.
  - Возможность свободного перетаскивания (touch-drag) без залипаний.
  - Индикатор активного спикера: пульсирующая рамка цвета лайма (`#C6FF33`).
  - При выключенной камере: инициалы пользователя на градиентной подложке + кнопка «Включить камеру».
- **Режим Fullscreen Call (Полноэкранный видеозвонок)**:
  - Раскрывается на 100% вьюпорта смартфона или экрана ноутбука.
  - Мобильный интерфейс спроектирован по образцу современных премиальных видеоконференций (FaceTime / VK Call):
    - Сплит 50/50 по вертикали: видео собеседника и локальное видео.
    - Верхняя стеклянная плашка — статус соединения, таймер урока, кнопка переворота камеры (front/back).
    - Нижний парящий док — ключевые кнопки вызова в пределах досягаемости большого пальца.

### 3. Мобильные шторки (BottomSheets)
- На смартфонах боковые панели (Чат, Файлы, Заметки) автоматически превращаются в свайповые нижние шторки.
- Радиус верхних углов: `32px`.
- Сверху располагается ручка свайпа: полоска `w-12 h-1.5 rounded-full bg-white/20`.
- Максимальная высота: `85vh - 92vh` с внутренней плавной прокруткой (`overflow-y-auto`).

## 6. Адаптивность и мобильная спецификация (Mobile First)

1. **Защита холста от сдвигов**:
   ```css
   html, body.cr-body, .cr-viewport {
     position: fixed;
     inset: 0;
     width: 100vw;
     height: 100dvh;
     overflow: hidden !important;
     touch-action: none;
   }
   ```
2. **Поддержка динамического вьюпорта iOS / Android**: использование `100dvh` вместо устаревшего `100vh`, предотвращающее прыжки интерфейса при скрытии адресной строки Safari/Chrome.
3. **Безопасные зоны (Safe Areas)**:
   - Верхние элементы: `padding-top: max(12px, env(safe-area-inset-top));`
   - Нижние доки: `bottom: max(16px, env(safe-area-inset-bottom));`
4. **Тач-оптимизация Excalidraw**:
   - Скрытие горячих клавиш клавиатуры (`.ToolIcon__keybinding { display: none !important; }`), сужающее кнопки до идеальных квадратных тач-мишеней.
   - Проброс кликов на холст через `pointer-events: none` на пустых контейнерах тулбаров.
