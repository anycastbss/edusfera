# Архитектура мобильного кабинета Edusfera (Mobile Aurora PWA)

Дата фиксации: 27 октября 2026 г.

---

## 1. Фундаментальная финансовая модель платформы
> [!IMPORTANT]
> **Платформа Edusfera не принимает оплаты за уроки внутри платформы и не осуществляет вывод средств репетиторам.**
> - Ученики рассчитываются с репетиторами **напрямую** (наличными, банковским переводом, картой или через ЕРИП).
> - Edusfera не удерживает комиссий за проведение уроков и не выступает платёжным шлюзом.
> - Раздел **«Финансы»** (`TabFinance.jsx`) предназначен исключительно для **расчётной аналитики и отчётности**:
>   - **Примерный доход за месяц**: рассчитывается автоматически как `Количество проведённых уроков × Часовая ставка репетитора (BYN/час)`.
>   - **Статистика**: отработанные часы, уроки за прошлый месяц, суммарное количество учеников.
>   - **Чеки НПД**: автоматическое формирование и учёт чеков для налога на профессиональный доход через интеграцию с сервисом МНС Республики Беларусь.
>   - **Запрет терминологии**: любые формулировки «Доступно к выводу», «Запросить вывод», «Кошелёк для вывода» категорически запрещены в интерфейсе.

## 2. Интерактивный онбординг (MobileOnboardingTour)
Для комфортного первого знакомства со смартфона реализован Stories-подобный обучающий гид (`MobileOnboardingTour.jsx`):
- **Стек**: React 19, `motion/react` (Framer Motion), Tailwind CSS, Lucide Icons.
- **Дизайн**: Glassmorphism (`backdrop-blur-2xl bg-black/85`), неоновые акценты Edusfera (`#7D39EB` и `#C6FF33`), сегментированный индикатор историй.
- **Сценарии по ролям**:
  - **Для Репетиторов (6 шагов)**:
    1. *Новый кабинет*: презентация автономности и скорости PWA Offline 2026.
    2. *График & Часы*: листание недель и быстрая настройка постоянных окон для записи (`AvailabilityBottomSheet`).
    3. *Персональная ссылка*: копирование ссылки `edusfera.by/tutors/{id}` для мессенджеров.
    4. *Быстрое создание урока*: плавающая кнопка `+` для назначения занятия в 2 клика.
    5. *ИИ-Методист 24/7*: автоматическая подготовка планов, квизов и задач ЦТ.
    6. *Доход & Уроки*: учёт расчётного заработка за месяц и формирование чеков НПД.
  - **Для Учеников (4 шага)**:
    1. *Приветствие*: все занятия прямо в браузере смартфона.
    2. *Видеокласс в 1 клик*: вход на занятие без ссылок и сторонних приложений.
    3. *Домашние задания*: PDF-конспекты с интерактивной доски и задания.
    4. *ИИ-Тьютор 24/7*: объяснение трудных тем в любое время.
- **Механизм вызова**:
  - Автоматически при первом входе (сохраняет флаг `edusfera_mobile_tour_completed_v1` в `localStorage`).
  - В любое время через кнопку **«Гид по новому кабинету»** во вкладке **«Профиль»** (`TabProfile.jsx`).
  - Через URL-параметр `https://edusfera.by/m?tour=1`.

## 3. Интерактивный календарь и синхронизация недель
- **Компонент**: `TabLessons.jsx`.
- **Локальный расчёт дат**: расчёт недель и дней изолирован от сдвигов временных зон (UTC+3) с помощью безопасных функций `formatLocalIso` и `shiftIsoDays`.
- **Оптимистичный UI**: смена недели происходит мгновенно в локальном стейте, параллельно отправляя запрос `/api/mobile/lessons?week_start=YYYY-MM-DD`.
- **Защита от сброса**: хук первичной загрузки изолирован через `useRef(currentWeekStart)` и не перезапускает `fetchLessons()` по кругу.
- **Rate Limiter**: лимит маршрутов `/api/mobile` увеличен до `120 req/min`.

## 4. Создание уроков для незарегистрированных учеников (Гостевой доступ)
- **Цель**: позволить преподавателю мгновенно организовать разовый урок с новым учеником без необходимости заставлять ученика предварительно регистрироваться на платформе.
- **Интерфейс создания (`CreateLessonBottomSheet.jsx`)**:
  - Переключатель «Выбрать из базы» / «+ Новый ученик».
  - Для нового ученика запрашивается только имя и (опционально) телефон.
  - В форме выводится подсказка: *«Подходит для разовых занятий. Ссылка на видеокласс появится сразу после создания. Для сохранения прогресса в базе ученику потребуется регистрация»*.
- **Криптографическая ссылка гостевого входа**:
  - Токен генерируется сервером на основе секрета приложения: `substr(hash_hmac('sha256', 'classroom_join_'.$lesson->id, config('app.key')), 0, 16)`.
  - Ссылка имеет вид: `https://edusfera.by/classroom/{lesson_id}/join?token={token}`.
  - Доступна через акцессор модели `$lesson->student_invite_url`.
- **Всплывающее окно после планирования**:
  - Показ готовой ссылки с кнопкой «Скопировать ссылку для ученика» (с анимацией подтверждения).
  - Кнопки быстрой отправки в 1 клик в **Telegram** и **WhatsApp** с предзаполненным вежливым текстом приглашения.
  - Кнопка быстрого перехода в класс для репетитора.
- **Ограничение прогресса в базе данных**:
  - Для незарегистрированных учеников система создает временный профиль гостя.
  - До момента регистрации ученика в Edusfera его история занятий, домашки и аналитика прогресса **не сохраняются в базе данных платформы**.
  - В онбординг-туре (`MobileOnboardingTour.jsx`, шаг 4) и карточке создания урока явно акцентировано, что для долговременных занятий и отслеживания динамики ученику рекомендуется зарегистрироваться.
- **Доступ к ссылке из карточки урока (`LessonDetailBottomSheet.jsx`)**:
  - В карточке любого назначенного урока репетитор видит блок «Ссылка для входа ученика (1 клик без логина)» и может в любой момент скопировать её или отправить повторно.
