# EDUSFERA PDF Test Generator

Локальный генератор печатных тестов EDUSFERA. Создаёт два PDF-документа формата A4:

1. **Тест для ученика** — условия, варианты ответов, графики/рисунки и отдельный бланк ответов.
2. **Ключ преподавателя** — таблица правильных ответов и пояснения к решениям.

Всё работает локально на вашем компьютере. Данные заданий и изображения не отправляются в сторонние сервисы.

## Возможности

- Русский текст и корректные кириллические шрифты.
- Чёрно-белый макет для экономной печати.
- Макет EDUSFERA: логотип, слоган, QR-код, параметры теста, инструкция, полосы разделов.
- Вопросы с четырьмя или пятью вариантами ответа (форма сейчас настроена на 5 вариантов A–E).
- Математические формулы в формате `$...$`, например `$x^2-5x+6=0$`, `$(x-3)(x+1)=0$`, `$\\frac{x^2-9}{x-3}$`.
- Загрузка графиков, геометрических чертежей и других изображений PNG/JPG/WebP.
- Автоматическая нумерация A1, A2, A3…
- Автоматическая пагинация A4 без разрыва стандартного задания между страницами.
- Отдельный бланк ответов; поля ФИО, даты и группы.
- Отдельный PDF-ключ с ответами и объяснениями.
- Импорт/экспорт заданий в JSON и загрузка теста-примера.

## Запуск на macOS

1. Установите Python 3.10 или новее (если ещё не установлен).
2. Распакуйте архив в удобную папку.
3. Дважды нажмите `start.command`.
4. При первом запуске скрипт создаст виртуальное окружение и установит библиотеки.
5. Откройте `http://127.0.0.1:8765` в браузере.
6. Чтобы завершить работу, вернитесь в окно Терминала и нажмите `Ctrl+C`.

При первом запуске macOS может показать предупреждение для `start.command`: нажмите правой кнопкой по файлу → **Открыть**.

## Запуск вручную на macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

Затем откройте `http://127.0.0.1:8765`.

## Запуск на Windows

Дважды нажмите `start_windows.bat`. После установки библиотек откройте `http://127.0.0.1:8765`.

## Как собрать тест

1. Заполните предмет, название, длительность, максимальный балл и URL для QR-кода.
2. Добавьте задания кнопкой **Добавить задание**.
3. Введите условие. Формулы оформляйте внутри `$...$`.
4. Заполните пять вариантов A–E и выберите правильный ответ.
5. Добавьте краткое пояснение для файла преподавателя.
6. При необходимости загрузите рисунок или график. Он будет встроен в PDF.
7. Нажмите **Сформировать PDF**.
8. Скачайте ученический вариант, ключ или ZIP-комплект.

## Формат математических формул

Формулы вводятся между знаками `$`. Примеры:

```text
Вычислите $2^3 \\cdot 5 - 4^2$.
Решите уравнение $(x-3)(x+1)=0$.
Упростите $\\frac{x^2-9}{x-3}$ при $x\\ne3$.
Найдите длину гипотенузы $\\sqrt{6^2+8^2}$.
```

Рендерер формул основан на Matplotlib MathText. Для сложных LaTeX-конструкций используйте загрузку заранее подготовленного изображения формулы или графика.

## JSON

Структура одного задания:

```json
{
  "number": "A1",
  "prompt": "Решите уравнение $(x-3)(x+1)=0$.",
  "options": [
    {"text": "−3"},
    {"text": "−1"},
    {"text": "3"},
    {"text": "−3 и 1"},
    {"text": "−1 и 3"}
  ],
  "correct": "E",
  "explanation": "Нули множителей: $x=3$ и $x=-1$."
}
```

Основной пример находится в `examples/example_test.json`.

## Требования

- Python 3.10+
- ReportLab
- Matplotlib
- Pillow
- qrcode
- Шрифт DejaVu Sans (обычно доступен через системный пакет DejaVu fonts)

## Ограничения текущей версии

- Текущий интерфейс предназначен для тестов с одним правильным вариантом ответа A–E.
- Сложные схемы, которые должны быть математически точными и редактируемыми, лучше загрузить как SVG/PNG из специализированного редактора; загрузчик принимает PNG, JPG и WebP.
- QR-код кодирует URL, введённый в настройках. Это не динамическая аналитическая ссылка.
- Это локальный инструмент одного преподавателя, а не многопользовательский облачный сервис.
